# Atlas dynamic diligence environment — collaboration proposal draft

Organizer: Apex Growth Systems LLC. Public lab: https://github.com/AAH20/project-atlas-due-diligence

Proposed environment: a synthetic AI infrastructure acquisition with a stage-filtered evidence catalog, budgeted investigator actions and deterministic scenario arithmetic. Agents read evidence, advance time and submit supported classifications/calculations. Replays expose actions and observed evidence, enabling reproducibility without private product code or internal model reasoning.

Current evidence: nine public development cases, three domains, material/clean/insufficient variants, tested staging and budget rules, JSON replays and Kaggle SDK adapters. This is a small implementation pilot; it is not independently validated institutional diligence and not yet an evergreen competitive game.

Before requesting official inclusion: add independently reviewed private scenario families, evidence-driven reversals, interrupted tools, calibrated abstention, economic utility and real cost telemetry. Separate fixed-scenario absolute metrics from pairwise outcomes; use scenario rotations, mirrored roles and frozen versions. Document protocol exploitation and keep material errors visible separately from win rates.

Possible future roles: buyer investigator and evidence custodian with explicit disclosure rules, plus a neutral deterministic oracle and blinded specialist review. Legitimate withheld information must be distinct from fabricated facts. A profitable negotiation outcome alone is insufficient evidence of accurate diligence.

Request to Kaggle: feedback on suitability for a simulation/Game Arena collaboration, supported harness integration, quotas and validation expectations. Official inclusion or model/lab endorsement is not assumed.
