# Atlas v0.2 commercial demonstration

Proposed offerings; not live subscriptions, completed client engagements or guaranteed outcomes.

| Offering | Deliverables | Scope controls |
|---|---|---|
| Readiness assessment | inventory, permissions, gaps, reviewer ownership, implementation plan | entities, sites, document count, deadline |
| Transaction diligence pilot | cited material findings, clean controls, uncertainty, reviewed decision packet | domains, scenario budget, specialist responsibilities |
| Continuous diligence intelligence | weekly source changes and actions; monthly milestone/exception review | update volume, counterparties, cadence, included hours |
| Institutional evaluation/integration | approved private corpus, held-out study, platform adapters | processing permissions, evaluation protocol, technical dependencies |

Four synthetic sample reports reside in `datasets/project-atlas/v0.2/outputs`. Reports are manually authored from deterministic timeline outputs, not generated by a live agent or reviewed client deliverables.

Measure cost per verified material finding, evidence freshness, reviewer rework, overdue actions and response time. Track service contribution margin using revenue minus attributable delivery/usage/infrastructure/support costs; label allocations. Do not claim saved capital, guaranteed financing, certification or legal assurance from fixture results.

Price only after discovery of actual workload and responsibility. Retainers need named deliverables, service hours, explicit limits and separately approved overages. Payment processing is outside this dataset release.
