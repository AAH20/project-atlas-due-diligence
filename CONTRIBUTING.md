# Contributing

Join the challenge: https://www.kaggle.com/competitions/frontier-due-diligence-challenge-season-1

Submit competitive entries as Kaggle Writeups under the published rules. Dataset issues/PRs are welcome for reconciliation errors, better clean/update cases, evidence locators and clearly labelled realism improvements. Preserve source lineage, tests and synthetic labels. Never submit real VDR/customer/PII data or private Investor OS workflows. Do not report public worked-answer reproduction as held-out performance. Contributions retain author attribution; no commercial IP assignment is a condition of participation. Include a licence/permission compatible with evaluation reuse. Commercial adoption needs a separate voluntary agreement.
